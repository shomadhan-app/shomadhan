# সমাধান (Shomadhan) — PWA

বাংলা-ভাষার তথ্য ও গাইড অ্যাপ। এটি একটি PWA: ওয়েবসাইটের মতো সার্চে পাওয়া যায়, আবার ফোনে অ্যাপের মতো ইনস্টল করে অফলাইনে চালানো যায়। কোনো সার্ভার বা বাড়তি লাইব্রেরি লাগে না।

## ফাইল তালিকা
| ফাইল | কাজ |
|---|---|
| `index.html` | মূল পাতা, সার্চ ইঞ্জিনের জন্য তথ্য (title, description) |
| `style.css` | ডিজাইন সিস্টেম (রঙ, কার্ড, বাটন, ডার্ক মোড স্বয়ংক্রিয়) |
| `app.js` | সব স্ক্রিন, নেভিগেশন, সার্চ, বুকমার্ক, শেয়ার, লেখার আকার |
| `data.json` | সব কনটেন্ট: বিভাগ, গাইড, অফিসিয়াল লিংক, নমুনা সেবাদাতা |
| `sw.js` | অফলাইনের জন্য সার্ভিস ওয়ার্কার (ক্যাশ) |
| `manifest.webmanifest` | ফোনে ইনস্টলের তথ্য |
| `icons/` | অ্যাপ আইকন |
| `robots.txt`, `sitemap.template.xml` | Google-এর জন্য |

## ১. অনলাইনে তোলা (বিনামূল্যে)
PWA চালাতে HTTPS ঠিকানা লাগে। বিনামূল্যে এর যেকোনো একটি ব্যবহার করুন:
- **GitHub Pages:** GitHub-এ নতুন repository খুলুন, সব ফাইল (icons ফোল্ডারসহ) আপলোড করুন, তারপর Settings > Pages থেকে branch `main` ও folder `/ (root)` বেছে Save করুন। ঠিকানা হবে `https://আপনার-নাম.github.io/repository-নাম/`।
- **Netlify Drop** বা **Cloudflare Pages:** ফোল্ডার আপলোড করলেই ঠিকানা পাবেন।

ফাইলের ভেতরের সব পাথ আপেক্ষিক, তাই সাবফোল্ডার ঠিকানাতেও চলবে।

## ২. ফোনে ইনস্টল ও অফলাইন
1. ফোনের Chrome-এ ঠিকানাটি খুলুন এবং ১০–২০ সেকেন্ড অপেক্ষা করুন (প্রথমবার ইন্টারনেটে লোড হলে ফাইল ক্যাশ হয়)।
2. Chrome মেনু (⋮) > **Install app** বা **হোম স্ক্রিনে যোগ করুন**।
3. এরপর ইন্টারনেট বন্ধ রেখেও অ্যাপ খুলে গাইড পড়া যাবে। অফিসিয়াল লিংক খুলতে ইন্টারনেট লাগবে।

## ৩. Google সার্চে আনা
1. ঠিকানা তোলার পর Google Search Console-এ (search.google.com/search-console) “URL prefix” দিয়ে সাইট যোগ করুন।
2. মালিকানা যাচাই করুন (`index.html`-এর `<head>`-এ Google-এর দেওয়া meta ট্যাগ বসিয়ে)।
3. `sitemap.template.xml`-এ `YOUR-DOMAIN` বদলে ফাইলের নাম `sitemap.xml` করুন, `robots.txt`-এর Sitemap লাইনটি চালু করুন, এবং Search Console-এ sitemap জমা দিন।
4. “URL Inspection” থেকে মূল ঠিকানার জন্য Request Indexing দিন।

কয়েক দিন থেকে কয়েক সপ্তাহ লাগতে পারে। “সমাধান” খুব সাধারণ শব্দ, তাই শুধু এটি লিখে সার্চ করলে উপরে আসার নিশ্চয়তা নেই। “Shomadhan” বা “সমাধান অ্যাপ জন্মনিবন্ধন NID গাইড” লিখে খোঁজা সহজ হবে।

## ৪. কনটেন্ট বদলানো
- গাইড যোগ বা পরিবর্তন করতে `data.json` সম্পাদনা করুন (গাইডের `id` অনন্য রাখুন)।
- যেকোনো ফাইল বদলালে `sw.js`-এর প্রথম লাইনের `VERSION` সংখ্যা বাড়ান, নইলে পুরনো ক্যাশ থেকে যেতে পারে।
- সরকারি তথ্যের গাইডে `"gov": true` থাকলে “অফিসিয়াল সাইটে নিশ্চিত করুন” চিহ্ন দেখায়। নিজে যাচাই করার পর যদি “সর্বশেষ যাচাই” তারিখ দেখাতে চান, সেই সুবিধা এখনো কোডে নেই (ভবিষ্যতের কাজ)।

## ৫. এখনকার সীমাবদ্ধতা
- সরকারি গাইডগুলো অনলাইন সূত্র (সংবাদ, দূতাবাস পেজ) থেকে সংকলিত খসড়া। ফি, কাগজ ও নিয়ম অফিসিয়াল সাইটে মিলিয়ে নেওয়া দরকার।
- সেবাদাতার তালিকা শুধু নমুনা (ডেমো), কোনো বাস্তব ব্যক্তি নেই।
- নোটিফিকেশন, রিভিউ, প্রোফাইল নিবন্ধন, লোকেশন ভিত্তিক খোঁজ নেই।
- ফন্ট (Hind Siliguri) প্রথমবার অনলাইনে নামে। না নামলে ফোনের নিজস্ব বাংলা ফন্ট দেখাবে।
- Play Store-এ দিতে চাইলে পরে এই PWA থেকে Android অ্যাপ বানানো যাবে (Trusted Web Activity)।
